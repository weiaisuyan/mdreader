# mdreader 1.0.6

本版移除应用内更新检查：mdreader 不再自动检查、下载或安装新版本，顶栏也不会再出现「有新版本」的提示。以后需要升级时，从 GitHub Releases 手动下载安装包覆盖安装即可。

## 右上角「有新版本」提示已移除

顶栏右侧的红色上传箭头、悬停提示以及它前面的分隔线都不再出现。

## 自动检查全部停用

- 启动后每 10 分钟执行一次的定时检查已删除；
- 每个窗口打开 30 秒后的检查已删除；
- 关于页的「检查更新 / 下载 / 取消下载 / 安装」按钮和下载进度条已移除；
- 主进程的 `check-update` / `download-update` / `cancel-download-update` / `execute-update` 四个 IPC 已移除。

`updateUtil.js` 的实现暂时保留在仓库里供历史参考，但启动流程、窗口生命周期和 IPC 都不再引用它。

## 以后怎么升级

打开 [Releases](https://github.com/weiaisuyan/mdreader/releases)，下载对应版本的 `mdreader-win32-x64-<版本>.exe`，双击覆盖安装。用户数据仍在 `%APPDATA%\mdreader`，不受影响；本版没有修改配置结构。

- 实现：`mdreader-web/src/components/layout/LayoutTop.vue`、`mdreader-web/src/views/AboutView.vue`、`mdreader-web/src/util/channel/eventUtil.js`、`mdreader-web/src/stores/counter.js`、`mdreader-electron/src/main.js`、`mdreader-electron/src/util/document-session/windowLifecycleService.js`、`mdreader-electron/src/util/channel/ipcMainUtil.js`、`mdreader-electron/src/util/updateUtil.js`
