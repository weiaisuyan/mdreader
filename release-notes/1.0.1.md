# mdreader 1.0.1

修复 1.0.0 里的窗口边框显示与文件拖拽浮层问题。

## 窗口边框

- **非最大化时四周边框不完整**：`frame: true` 会带回系统的可调边框（`WS_THICKFRAME`），实测内容区比窗口外框小 14×8px，渲染层那条 1.33px 的青色边框只能画在内容区内，被窗口边缘裁掉，只剩圆角弧线露出一点 —— 表现为「只有最大化时四周才有边框，平时只有四个角有点青色」。
  - 改用 `thickFrame: false` 去掉可调边框，客户区与窗口同尺寸（实测 1920×1045 完全一致）
  - 但 Electron 关掉 thickFrame 时会连带去掉 `WS_CAPTION`，系统动画随之消失
  - 因此新增 `windowStyleUtil`：窗口建好后用 koffi 直接调 `user32.dll`，只补回 `WS_CAPTION`、不补 `WS_THICKFRAME`
  - 补回的 `WS_CAPTION` 仍带 1px `WS_BORDER` 非客户区，边框 div 再从 `inset: 0` 改为 `inset: 1px`，完整落在可见区内
- 结果：**系统动画与四边完整边框同时成立**（`WS_CAPTION=True`、`WS_THICKFRAME=False`、客户区=外框）

## 文件拖拽

- **拖文件时浮层显示的是文件内容缩略图**：代码里从未设置 `setDragImage`，Chromium 默认抓取被拖列表项的整块快照，列表项带缩略图时用户看到的就是一张内容缩略图，认不出在拖哪个文件。
  - 改为现造一个只含文件名的小块（深色底、青色描边、圆角、单行省略）作为 drag image

## 标签与分栏

- **空白标签栏拖入不再分栏**：某一栏只有一个「无文件路径 + 无未保存修改」的标签时，从文件列表或资源管理器拖入视为「就在这一栏打开」，直接顶替空标签；同时这类栏不再画出分栏预览，避免预览与实际行为不一致

## 依赖

- 新增 `koffi ^3.3.7`（纯 JS 的 FFI 库，用于调用 `user32.dll` 补窗口样式位）
