# mdreader 1.0.2

修复 1.0.1 的一个隐私与体验问题：新装的应用第一次启动就自动打开上一次会话里的个人笔记。

## 首次启动自动恢复旧标签页

1.0.1 的旧数据迁移会把旧版 `文档/wj-markdown-editor` 目录下的 `recent.json`（最近文件）与 `tab-group.json`（上次打开的标签组）整包搬进新数据目录。这两个文件记录的是「上一次打开过哪些文档」，属于会话状态，不是用户设置。结果就是：装好一启动，应用直接恢复上次的标签页，把用户的个人文档路径摊在窗口标题和标签栏上。

- 迁移白名单收窄：只迁移 `config.json`、`logs/` 与 `config.corrupted.*.json` 备份，`recent.json` 与 `tab-group.json` 一律不迁移
- 全新安装从空白状态开始，不再恢复任何旧标签
- 已用 1.0.1 迁移过的安装，升级后首次启动会一次性清理这两个遗留文件（独立 marker `.migrated-session-state-cleared` 保证只清一次，之后正常使用产生的标签组不会被误删）
- 清理发生在 `initTabGroup` / `initRecent` 读盘之前，因此升级当次启动就是空白窗口

## Linux 更新信息

- AppImage 的 `appimage-updateinformation` 与发布工作流里的 `gh-releases-zsync` 目标从上游账号 `nlbwqmz` 改为 `weiaisuyan`，避免自动更新指向别人的仓库

## 升级说明

- Windows 直接覆盖安装即可，用户配置、日志与最近文件菜单不受影响；上次的标签页不会在升级后自动恢复，需要手动打开
