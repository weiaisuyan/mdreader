# mdreader 1.0.0

首个独立版本。基于 [wj-markdown-editor](https://github.com/nlbwqmz/wj-markdown-editor) 3.1.1（MIT 协议）
的自维护分支，在此版本完成品牌独立与一批交互/渲染缺陷修复。

## 品牌

- 应用更名为 **mdreader**，可执行文件 `mdreader.exe`
- 全新图标（深色底 + 白色 `md` + 青色横线），覆盖 16 / 24 / 32 / 48 / 64 / 128 / 256 / 512 / 1024 全尺寸与多尺寸 `.ico`
- 应用身份 `AppUserModelId` 改为 `com.mdreader.app`
- 窗口标题、关于页、引导文案、导出水印默认文案、页面标题全部同步
- 用户数据目录迁至 `%APPDATA%\mdreader`；启动时若新目录不存在且旧目录有数据，整目录复制过去，复制失败则回退使用旧目录，避免升级后配置与标签丢失

## 窗口

- 改用 `titleBarStyle: 'hidden'` 取代 `frame: false`，恢复系统原生动画：最小化/还原、最大化、任务栏图标点击的过渡效果与系统窗口一致
- 双击顶栏空白可最大化/还原
- 点击编辑区或标签条空白不再切换焦点栏，焦点只由点击标签决定

## 标签页

- 标签宽度改为按内容自适应：名字短时不再被撑到固定宽度留出大片空白；超过 240px 才截断
- 「新建标签」按钮紧跟在最后一个标签之后，不再固定在栏的最右侧
- 标签变多时仍靠压缩容纳，不出现滚动条

## 分栏

- 分栏宽度改为按「目标栏一分为二」计算：被拆的栏减半，其余栏宽度不动（此前 3 栏会变成 1:1:2，4 栏会被挤成一排）
- 栏布局上限从 2 栏放开到 4 栏，并对齐渲染层的 `MAX_PANE_COUNT`
- 分栏时主动持久化栏宽（此前只在拖动栏间分隔条时才写盘，导致重启后栏宽丢失）
- 单栏状态下把标签拖到编辑区**左边缘**可真正在左侧开出新栏（此前只画预览、松手无反应）

## 修复

- 拖入文件偶发完全无反应：`resolveOpenedSessionId` 的兜底分支调用了已被删除的 `matchesTarget`，抛出的 `ReferenceError` 被 async 处理器吞掉
- 空文档占位状态下插图溢出容器：「文档内容为空」文字与「去编辑」按钮被压在图标上
- 多栏切换焦点时，切换前的正文收敛使用焦点栏自己的编辑器，避免写错栏

## 构建

- GitHub Actions 工作流中的目录引用同步为 `mdreader-web` / `mdreader-electron`
- `installer.nsh` 的图标注册指向 `mdreader.exe`（原指向已不存在的旧文件名）
- Linux 包的 AppStream 元数据（组件 id、描述、桌面项、仓库链接）更新为 mdreader
