# mdreader 1.0.5

两处阅读体验修复：纯预览态在窗口最大化/还原、侧栏或大纲栏显隐、分栏宽度调整后保持当前阅读位置；右侧滚动条不再被分隔手柄抢走命中区。

## 纯预览阅读位置在窗口缩放后漂移

**现象**：在纯预览态阅读长文时，最大化或还原窗口，正文会跳到别处；先双栏、再切到纯预览后最大化，跳动更明显，甚至直接回到文档前部。

**原因**：

1. 预览区只记录像素 `scrollTop`。纯预览正文宽度是窗口的 80%，窗口变宽后长段落重新换行、整篇高度缩短，同一个像素值自然落到更靠后的段落。
2. 纯预览时编辑器只是隐藏、没有销毁。窗口缩放让隐藏的 CodeMirror 因换行变化调整自己的滚动位置并发出 `scroll`，联动逻辑又把它反推回预览区，覆盖掉本应保持的位置。

**修复**：

- 纯预览态每次滚动记录视口顶部的正文块（行范围 + 块内比例）；预览容器宽度变化后按新布局把同一行重新顶回视口顶部。
- 隐藏的编辑器不再反向驱动预览；只有模式切换、预览刷新这类显式交接仍然放行。
- 预览刷新完成后再补采一次锚点，覆盖图片 / 图表撑开导致的「没有滚动但结构变了」。

- 实现：`mdreader-web/src/components/editor/MarkdownEdit.vue`、`mdreader-web/src/components/editor/composables/usePreviewSync.js`、`mdreader-web/src/components/editor/composables/__tests__/usePreviewSync.test.js`

## 拖滚动条总是变成调整右侧大纲栏宽度

**现象**：想拖预览区右侧的滚动条，鼠标却频繁触发大纲栏宽度调整；滚动条本身只有很窄一条能点中。

**原因**：预览滚动条在编辑器栏最右侧，宽 8px；右侧大纲栏的纵向分隔手柄 `.wj-sash--vertical` 原来向左右各扩 6px 命中区，正好盖住滚动条约 6px，只剩约 1.5px 可点。

**修复**：

- 纵向分隔手柄命中区改为左 2px / 右 6px，把左侧让给滚动条。
- 滚动条命中宽度 8px → 10px，透明边框同步从 2/1 调到 3/2；视觉仍是 4px 细条、悬停 6px，不改变观感。

- 实现：`mdreader-web/src/assets/style/sash.scss`、`mdreader-web/src/assets/style/scroll.scss`

## 升级说明

Windows 直接覆盖安装即可。用户数据仍在 `%APPDATA%\mdreader`，不受影响；本版没有修改配置结构。建议升级后在纯预览态最大化 / 还原一次，并确认拖动右侧滚动条不再触发大纲栏宽度调整。
